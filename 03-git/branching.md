# Branching

- **MUST** branch from `main`; **MUST NOT** commit / push directly to `main`.
- **MUST** name branches `<type>/<short-description>`: `feature/login-google`, `fix/cart-total`, `hotfix/payment-timeout`, `chore/update-deps`.
- **SHOULD** use one branch per task; update from `main` before opening a PR.
- **MUST NOT** force push, delete branches, or rebase shared branches without approval.

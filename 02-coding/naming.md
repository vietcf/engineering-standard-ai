# Naming

- **MUST** use names that convey meaning; **MUST NOT** use cryptic abbreviations (`userCount`, not `uc`).
- **MUST** follow the language convention for variables / functions (camelCase, snake_case...).
- **MUST** use PascalCase nouns for classes / types (`OrderService`).
- **MUST** start function names with a verb (`getUser`, `calculateTotal`).
- **MUST** prefix booleans with `is/has/can/should` (`isActive`).
- **MUST** use UPPER_SNAKE_CASE for constants (`MAX_RETRY`).
- **SHOULD** name files / folders in kebab-case or per framework convention.
